# Licensing

This repository mixes code, data and writing, so it carries three licenses.
The rule is by kind of content, not by directory alone.

| Content | License | File |
|---|---|---|
| **Code**: `src/`, `tests/`, `examples/`, `web/`, and every script under `experiments/*/*/scripts/`, `research-outputs/*/*/` (figure/number scripts; dataset scripts under `research-outputs/data-papers/` are Data, below), `blog/scripts/` and `experiments/_lib/` | MIT OR Apache-2.0 (your choice) | [`LICENSE-MIT`](LICENSE-MIT), [`LICENSE-APACHE`](LICENSE-APACHE) |
| **Data**: generated result files under `experiments/*/*/results/` (CSV, TSV, JSON, run logs, rule lists); everything under `research-outputs/data-papers/` (dataset CSVs, build JSON records, and their build scripts and READMEs); and any dataset deposited on Zenodo or a similar archive | CC0 1.0 (public domain dedication) | [`LICENSE-CC0-1.0`](LICENSE-CC0-1.0) |
| **Writing and figures**: `notes/`, `blog/` posts and pages, `experiments/*/*/README.md`, `NOTEBOOK.md`, `notebook.ipynb` prose, the manuscripts in `research-outputs/` outside `data-papers/` (Typst source, `main.pdf`, `fig/`), `AGENTS.md` and other documentation | CC BY 4.0 | [`LICENSE-CC-BY-4.0`](LICENSE-CC-BY-4.0) |

Notes:

- Data are dedicated to the public domain so they can be reused and
  redistributed without conditions. Citation is still the scholarly norm: please
  cite the repository (and the Zenodo record, where one exists) and the commit
  you used.
- Figures plotted from the data are CC BY 4.0; the numbers underneath them are
  CC0.
- `research-outputs/data-papers/` is CC0 as a whole, including the build
  scripts and READMEs, so each dataset can be reused together with the script
  and documentation that describe it.
- Bulk output that is not committed (`dumps*/`, `knock*/`, `scratch/`) is
  regenerated by the scripts and follows the same rule as the committed data.
- A Zenodo deposit should state CC0 for the data and name the commit that
  produced it, as `AGENTS.md` requires for every result.
- Rust dependencies (`rayon`, `proptest`, `cudarc`) and Python dependencies keep
  their own licenses; none is vendored in this repository.
- Contributions are accepted under the license that matches the kind of content
  they add, as above. Unless you state otherwise, a contribution of code is
  dual-licensed MIT OR Apache-2.0, as in Apache-2.0 section 5.
