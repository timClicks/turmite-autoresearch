# Proposed output contract

No data are present. Final column definitions and units must be frozen with
registration. All rows keyed by experiment/run, rule, start seed, arm and band.

- `results/manifest.json`: exact command, UTC and NZDT timestamp, git commit,
  dirty source hashes, config hash, input hashes, explicit rule/seed list,
  initial-patch convention, seed roles, folds, estimator, software versions.
- `results/runs.csv`: rule, base_rule (when paired), arm, seed, band, area_start,
  area_end, steps, B, I, P_end, A_end, mean_P_over_A, kappa_endpoint,
  kappa_time_normalized, attained, escaped, censored_steps, completion_status.
  Define both normalizations explicitly; never mix them in a model or figure.
- `results/features.csv`: rule/seed/arm/band, named feature, value, units,
  cell_or_step_weighting, normalization, sample_count, censor_lower, censor_upper.
  Tail: duration-bin counts/time sums and boundary/interior means. Prefix:
  colour/depth exposure, launch/return counts, first divergent turn. Gates:
  directed crossings, moving-map reclassifications, concentration, edit exposure.
  Age: census age/visits/cycles, separate exposure-weighted features and hazards.
  Only the experiment's relevant feature family is needed; no arbitrary search.
- `results/predictions.csv`: held-out rule/base, band, target seed role, model,
  fold, observed and predicted target, baseline prediction, coverage status.
- `results/analysis.json`: calibration, coverage and reliability gates;
  per-prediction estimates, seed sd, bootstrap intervals, exact verdicts,
  exclusions, limitations, exploratory labels, and hashes of every input.
- `dumps/`: optional episodes, spatial crossing maps, snapshots and checkpoints.
  No raw dumps in the notebook or cross-experiment imports.

Counts B+I must equal steps. Include incomplete episode fragments, not just
completed cycles. Unattained targets produce explicit status rows; never zeros
masquerading as measurements. A `.done` marker means verified output completion,
not scientific success. Keep bounded summaries small enough to commit.

## Implemented pilot contract (2026-10-15; supersedes draft for feasibility only)

`pilot-v2.manifest.json` freezes rules, explicit seeds, initial patch convention,
source/input SHA-256, cap, board, bands, worker count and commands. Compact
`pilot_features.csv`, `pilot_summary.json`, calibration files, and cell-weighted
`pilot-v2.*.census.csv` live in results/. The pilot audit includes all requested
specs and hashes of local raw payloads. `REPORT.md` is generated by scripts/report.py.

Local per-trajectory payloads are under dumps/pilot-v2/{ants,controls}/:
- bands.csv: departures from tau(lo) through tau(hi)-1; B+I=steps;
  sum_pa=sum_t(P_t/A_t); complete-contained B/I counts and time sums, clipped
  in-band time, full interior-episode follow-up and unresolved in-band overlap.
- bins.csv: floor(log2(duration)) bins. I_intersect counts whole resolved episodes
  intersecting the band; entry_count/entry_time_sum further require entry in band.
  Full duration sums are distinct from in-band overlap and can exceed band time.
  B_contained/I_contained are the existing accountant's complete-contained episodes.
- age.csv: exact cell-weighted rim census at tau(lo), tau(mid), tau(hi).
  Boundary depth is 0 and the rim includes depths <=4 to any visited boundary.
  immature=fraction(visits<n), median_log_age=median(log(1+t-birth)),
  cycle_variance=population variance of floor(visits/n) over rim cells.
- hazards.csv: step-weighted departure risk/transition counts, conditioned jointly
  on B/I, floor(log2(1+age)), floor(log2(1+visits)), incoming heading and phase.
  A B->I event is departure/entry risk; I->B is return risk for this moving label.
  Counts sum to executed departures, never the final unexecuted state.
- status.csv: final step, stop reason, visited-cell count and history struct bytes.
- .done: atomic finished-output marker with source/config identity. Completion of
  an output is not attainment or scientific success. Mid-run state checkpoints
  are not implemented and the pilot does not meet that production requirement.

Discovery counts arrivals (including origin at t=0); visits count departures.
For ants, phase=(initial_colour+visits)%n, and full observed cycles=visits//n.
Initial patch colours are recorded phase offsets, not inferred prehistory.
A right-censored return has no assumed finite upper bound. unresolved_overlap
is a known lower bound on the unresolved episode's full duration, not an unbiased
completed-episode mean. Unattained bands remain explicit zero-coverage status rows;
feature nulls are missing measurements, not zero effects. No kappa model is fit.
