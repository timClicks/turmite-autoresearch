# cell1: single-cell knockout refinement (frontier item 10)

Question and hypotheses (written 2026-10-13, before any single-cell run) are in
`notes/frontier-results.md` (search "single-cell"); the status row is item 10 in
`notes/frontier-status.md`. Result there: one cell can cost 4-5% of the tether
(null p99 1-2%); three cells reproduce the 3x3 effect, saturating near 0.15.

Rules: RRRRRLLLLLL, RLLLLRRRRLR. Each run is a deterministic fresh ant, 2^26 steps.

## Reproduce
```bash
# runs (Rust example; reads legacy experiments/archive/2026-10-knockout-maps/dumps/RULE.grid and experiments/archive/2026-10-knockout-maps/knock/RULE/refine3.csv)
cargo run --release --example cell1 -- experiments/archive/2026-10-knockout-maps/dumps/RULE.grid RULE 67108864 \
    experiments/archive/2026-10-cell1/results/RULE <three 3x3 window corners>
# windows: RRRRRLLLLLL -7,-10 -7,-11 -5,-15; RLLLLRRRRLR -1,7 1,6 -2,8
# stats (from repo root; reads experiments/archive/2026-10-knockout-maps/knock/RULE/summary.json, read only)
uv run experiments/archive/2026-10-cell1/scripts/cell1_stats.py > experiments/archive/2026-10-cell1/results/cell1_stats.txt
```
