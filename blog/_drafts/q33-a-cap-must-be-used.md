Q33 asks whether a bound on fresh runs sets the width at which growth becomes compact. There is a trap in the intervention: raising an upper bound need not change the lengths the walker actually uses. With random R/L/U turns, reversal usually ends a fresh run long before a large cap is reached. With the rule's own first turn, a square closes first.

The [new proposal](https://github.com/timClicks/turmite-autoresearch/tree/exp/q33-cap-crossover-proposal/experiments/proposed/2026-10-q33-cap-crossover) instead fixes a policy that usually goes straight on fresh ground, varies only the cap, and compares each capped walker with the same uncapped policy. A straight branch gives an active spatial scale on a flat boundary. Real ant boundaries may cut that branch short; the excluded pilot must check exposure before confirmation.

This repair changes what we can expect. Persistent fresh motion may start ballistically, and it may create ordered structures. Borrowing the old porous exponent without calibration would replace one untested assumption with another. The proposal therefore scores the original numerical prediction separately from the broader cap-dependent crossover. It contains no new measurements. Calibration, detector checks and a further confirmation freeze still come first.
